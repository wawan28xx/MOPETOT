 1. STATUS FITUR YANG SUDAH ADA (per 28-10-2026)
================================================================================

A. CORE SCAN ENGINE
--------------------------------------------------------------------------------
- Multi-platform unpacker: APK/AAB, IPA, DEX, native SO, PE, Hermes HBC (.hbc),
  Flutter (libapp.so via blutter — Dart 3.9.2 / 3.10.0 / 3.12.2, build cache
  vendored di bin/blutter_src/build), Unity IL2CPP (Android), .NET (ilspycmd).
- Regex DB 87+ rules (rules/secrets.json) + noise filter library 3rd-party
  (is_library_source / LIBRARY_NOISE_PATHS) + dedupe rule bising.
- Rule PEM dirapatkan (header PEM wajib body base64 >= 32 char) — regression
  test_pem_rules.py.
- Fitur PII yang dihapus sesuai request: credit_card_number,
  bank_account_number, idn_nik_ktp.
- FairPlay/cryptid detection (parser Mach-O pure-Python, 32/64-bit LE/BE,
  fat/universal multi-slice) -> finding ios_fairplay_encrypted.

B. iOS REVERSE ENGINEERING (SUDAH DEEP — hasil sesi terakhir)
--------------------------------------------------------------------------------
- ObjC Class-Dump parser pure-Python (engines/objc_dump.py): baca langsung
  __objc_classlist -> class_t -> class_ro_t; method list legacy (24-byte) +
  relative/small (12-byte); ivars, properties, protocols, kategori; chained
  fixups (iOS 15+); flag Swift. Pengganti rabin2 -C (rusak di radare2 6.x
  Windows — "UnnamedClass").
- Partial FairPlay dump: binary cryptid tetap di-inventory (122 class + jumlah
  method/ivar/prop dari __objc_const/__objc_data yang plaintext), nama selector
  di-recover dari debug symbols __LINKEDIT (framework pth-3: Realm 63 class),
  ditandai nama class anonim <class-anon-N> bila tak recoverable.
- Swift symbol demangler parsial (_$s9Alamofire7SessionC10cachedResp ->
  Alamofire.Session.cachedResp).
- ObjC Inspector (modal browse class/method per binary, banner FairPlay,
  snippet hook per method) + iOS Hook Generator (selector login/auth/token/
  crypto/keychain, prioritas class milik app sendiri).
- Endpoint rescan in-place: POST /api/scan/{id}/rescan + tombol di UI.
- Info.plist decode (plist_decoded/), ATS + URL scheme analysis
  (manifest_analyzer), embedded.mobileprovision decode.

C. FLUTTER DEEP SUPPORT
--------------------------------------------------------------------------------
- Blutter dump scan (pp.txt/asm/objs) + blutter_frida.js helper.
- Dart Inspector: inventory package + function + route Flutter, filter,
  diff antar 2 scan (dart_function_diff).
- Dart Hook Generator presisi (offset pasti per function Dart) + AI Dart
  context (summarize_dart_context untuk prompt agent).
- mitm addon generator (tag response berdasarkan korpus) + Frida Runner
  (spawn app di device via adb + inject script, output streaming).
- Auto-chain login suggestion (endpoint + kredensial dari temuan ->
  suggestion login test).

D. POC & RASP
--------------------------------------------------------------------------------
- RASP Bypass Generator (terpisah dari One-Click PoC): RASP-aware baca
  findings.json (rasp detected) -> generate Frida script sesuai musuh
  (anti-frida-detection native block, RootBeer/AppSealing hook khusus,
  SSL/root/biometric bypass, crypto dumper) + tombol Run di Device.
- One-Click PoC & Exploit Generator: ADB command builder untuk exported
  activity/service/receiver + deep link trigger, PoC cache.
- Custom Deep Links & Exploit Trigger table dengan Copy ADB PoC.

E. LIVE VERIFIER (paralel — tidak saling menunggu)
--------------------------------------------------------------------------------
- Firebase Realtime DB CRUD tester (open read/write check).
- Google Maps & Cloud API Key Suite Checker — 24 scope, 4 kategori
  (Maps Core 10, Maps Extended 6, Cloud AI/Data 6, Key Intel 2), eksekusi
  paralel (~3-6 detik), klasifikasi BODY-FIRST (HTTP 200 bisa REQUEST_DENIED
  di dalamnya): ACTIVE / INVALID KEY / API NONAKTIF / IP-REFERER RESTRICTED /
  API RESTRICTION / CLIENT-PACKAGE RESTRICTED / KUOTA / OAUTH-ONLY.
  Field key_valid + verdict DEAD_KEY utk key mati.
- AWS STS GetCallerIdentity, Stripe key, Slack/Discord webhook,
  generic endpoint probe, credential login test (module credentials).
- Verification cache persist per scan.

F. AI / AGENT
--------------------------------------------------------------------------------
- Validate Finding (Agent AI): validate SEMUA (default) atau per-temuan,

 2. WORKLIST POTENSI PENGEMBANGAN (MASIH RELEVAN, URUT PRIORITAS)
================================================================================

[P0] 1. HARDENING TOOLS SENDIRI (30 menit — dampak terbesar)
   - app.py masih bind 0.0.0.0 (line ~2188): ubah ke 127.0.0.1, atau jadikan
     konfigurasi (env MOPETOT_HOST) bila butuh akses LAN dari device test.
     Login auth + pin starlette<0.41 SUDAH selesai — ini sisa terakhirnya.
   - Catatan: data temuan = data klien, jangan expose tanpa sengaja.

[P1] 2. CROSS-APP SECRET REUSE DETECTOR (1-2 hari — fitur unik)
   - Correlate secret lintas scan di DB (sama nilai / sama prefix high-entropy)
     -> temuan level organisasi (reuse lintas app klien sama).
   - Tanpa ini, agent validasi sudah menyebut cross-check tapi belum otomatis.

[P1] 3. DATA-FLOW / TAINT TRACKING SEDERHANA (2-4 hari)
   - Regex murni belum membuktikan alur data: Intent/Deep Link/query ->
     sink berbahaya (WebView.loadUrl, Runtime.exec, openFile,
     addJavascriptInterface SDK rendah).
   - Versi pragmatic: call-graph smali sederhana (invoke-* -> method) untuk
     inject konteks caller/callee ke prompt AI (pola Droid LLM Hunter) —
     80% nilai call-graph, 20% effort. Full taint tracking jadi P3.

[P1] 4. LOGIC DEEP LINK PoC (lanjutan validasi)
   - Deep link PoC saat ini true-positive rate bagus tapi masih level
     "ada scheme" — tambah: parameter query dari kode (getQueryParameter),
     cek host/path yang benar-benar di-handle (intent-filter data vs kode),
     HTML auto-trigger utk scheme hijack.

[P2] 5. SAST RULES KRIPTO & INSECURE CODING (1 hari)
   - AES/ECB/PKCS5Padding, hardcoded IV (SecretKeySpec literal),
     java.util.Random utk token, TrustAllCerts / ALLOW_ALL_HOSTNAME_VERIFIER,
     FLAG_MUTABLE PendingIntent (33554432), addJavascriptInterface targetSDK<17.
   - Pattern YAML DLH layak di-port: strandhogg, pending_intent_hijacking,
     zip_slip, insecure_webview.

[P2] 6. BADGE OWASP MASVS + TRIAGE STATUS (1 hari)
   - masvs_mapping.json (rule -> MASVS ID + referensi) + kolom triage di DB
     (False Positive / Verified / Needs Test) + tombol di tabel temuan.
   - Triage status sangat menghemat waktu hunter — statusnya persist lintas
     rescan.

[P2] 7. EXPORT SARIF/JSON + TEMPLATE LAPORAN BOUNTY (setengah hari)
   - SARIF utk CI/GitHub Security; template laporan HackerOne/Bugcrowd
     (judul + deskripsi + repro + impact, nilai ter-mask per policies).

[P2] 8. APK SIGNATURE ANALYSIS v1/v2/v3/v3.1 (setengah hari)
   - Fingerprint, key rotation, debug cert detection. Bisa via REA
     inspect_apk_signature (lihat bagian 3) atau implement mandiri (apksigner
     verify --print-certs di bin/).

[P2] 9. JNI MAPPING TABLE (1 hari)
   - native method Java (jadx) <-> exported symbol Java_com_... di .so
     -> hunter tahu library mana dibuka di Ghidra (bin/ghidra lokal, lihat
     catatan push).

[P2] 10. DETEKSI ASSET TERENKRIPSI (setengah hari)
   - SQLite header bukan "SQLite format 3", blob custom, aset .enc ->
     flag "butuh runtime dump" + hint ke Frida dumper.

[P2] 11. OPSI C+D PoC ENGINE: HTML EXPLOIT BUILDER + PYTHON LOGCAT PoC (1-2 hari)
   - Opsi A (parameter extractor) & B (Frida generator) sudah jalan;
     lanjut: template HTML auto-redirect utk scheme/deeplink hijack +
     runner python (adb + logcat assertion utk crash/token leak).

[P3] 12. REPACKAGING HELPER OFFLINE (2-3 hari)
   - apktool b + apksigner, injeksi Frida gadget / patch manifest
     exported=true (repackage-test klien perlu izin tertulis di scope!).

[P3] 13. VERSION CORPUS DIFF (1-2 hari)
   - Diff manifest + smali antar 2 versi APK klien -> patch-diff hunting
     (versi baru = attack surface baru).

[P3] 14. IL2CPP WINDOWS GAME ROUTE (setengah hari)
   - GameAssembly.dll (PE) -> dispatch ke Il2CppDumper (tool sudah ada
     di bin/, tinggal routing PE -> unity_engine).

[P3] 15. UPLOAD RETENTION JOB (setengah hari)
   - web/uploads sudah > 2 GB — auto-purge upload > 30 hari + tombol bulk
     delete di history page.

[P3] 16. LIVE ADB DEVICE INSPECTOR lanjutan (2-3 hari)
   - Frida Runner sudah ada; lanjut: one-click install APK, pull
     /data/data/<pkg>/ (SharedPreferences, SQLite, cache WebView),
     test allowBackup via adb backup.

[P3] 17. GHIDRA INTEGRATION (optional)
   - bin/ghidra_12.1.2_PUBLIC (lokal, tidak di-push — 884 MB): headless
     analyzeHeadless utk decompile function menarik hasil JNI mapping /
     ObjC dump. Baru worth it kalau P2#9 jalan dulu.
